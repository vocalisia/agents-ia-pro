## 📋 WORKFLOW OUTREACH (2h de boulot max)

### Étape 1 — Validation emails (20 min)
- Tester chaque email via **Hunter.io** (gratuit 25 recherches/mois) ou **RocketReach**
- Si email fondateur pas trouvé → utiliser `hello@` / `contact@` / `partnerships@` (priorité dans cet ordre)
- Backup : envoyer LinkedIn message direct (même texte condensé)

### Étape 2 — Personnaliser le pitch (30 min)
Pour chaque prospect, adapter 3 variables du template `PITCHS-MONETISATION.md` section 1 :
- `{{Prenom}}` : prénom fondateur
- `{{NomProduit}}` : nom exact produit
- `{{Categorie}}` : "Voice AI", "Chatbot", "Automation", etc.

### Étape 3 — Envoi (30 min)
- **Envoyer depuis `contact@vocalis.pro`** (domaine cohérent, fait déjà trafic)
- **Mardi ou mercredi, 10h-11h heure FR** (meilleur taux d'ouverture B2B)
- Objet court : "Featured Listing {{NomProduit}} sur Agents-IA.pro ?"
- Signature : Laurent Duplat + lien /editeurs.html

### Étape 4 — Tracking (10 min setup)
- Créer pipeline CRM (HubSpot free, Pipedrive trial, ou simple Google Sheet)
- Statuts : `sent → opened → replied → negotiation → closed-won/lost`
- Relance à J+3 (1 ligne), J+10 (valeur ajoutée : envoi d'un insight IA gratuit)

### Étape 5 — Conversion attendue
- **20 envois** → 50-70% ouverture = 12-14 lectures
- **12 lectures** → 25-30% réponse = 3-4 réponses
- **3-4 réponses** → 40-50% call = 1-2 calls
- **1-2 calls** → 50-60% close = **0-1 deal closed** au premier pass

→ Répéter cycle toutes les 2 semaines avec **nouvelle cohorte de 20 prospects**.
→ Objectif 90j : 15 Featured Listings actifs × 299€ = **4 485€ MRR**.
